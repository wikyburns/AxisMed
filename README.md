📦 3D Foot & Foambox Landmark Detection SDK

The 3D Foot & Foambox Landmark Detection SDK provides automatic analysis and landmark detection for 3D scans of feet, plantar surfaces, and phenolic foam boxes (Foambox and Dual Foambox).
This SDK removes the need for manual landmarking, alignment, and foot differentiation—dramatically reducing workflow time and increasing accuracy.

🚀 Features
✅ Automatic Foot Detection

The SDK analyzes a 3D mesh and detects:

Single foot scan

Plantar surface scan

Foambox scan

Dual Foambox scan (two feet at once)

It automatically identifies whether the scan contains:

One foot

Two feet (left & right differentiation included)

🎯 Landmark Detection

For each detected foot, the SDK returns key anatomical landmarks:

First Metatarsal

Fifth Metatarsal

Heel Center

These landmarks are generated with high precision, enabling automatic downstream processing.

🦶 Left/Right Foot Detection (Dual Foambox)

For dual foambox scans, the SDK:

Detects both feet simultaneously

Automatically classifies them as left or right

Returns separate landmark coordinates for each foot

📏 Automatic Alignment

Once the landmarks are detected, the SDK automatically:

Aligns the 3D scan to a consistent orientation and plane

Normalizes rotation and position

Prepares the scan for design engines (e.g., insole design, orthotics design)

This ensures every scan is instantly ready for processing—no manual corrections required.

🧩 Why This SDK Matters

Eliminates manual landmark selection

Removes human error

Standardizes scan orientation

Enables instant preview and automated design pipelines

Essential for high-efficiency orthotics, podiatry, and 3D foot analysis workflows
